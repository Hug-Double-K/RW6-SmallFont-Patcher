# 카메라 셔터 — 안정판 정리 (2026-11-23 확정)

워치(REDMI Watch 6 중국판)에서 폰 카메라를 찍는 기능입니다. 사용자가 세워서·양쪽으로 눕혀서 사진, 동영상, 일시정지, 다시 촬영, 끝내기까지 모두 확인했습니다.

## 안정판 파일

| | 파일 | 버전 |
|---|---|---|
| 워치 앱 "카메라 셔터" | `RW6Cam_V1.6.rpk` | 1.6 (versionCode 7), 패키지 io.github.hugdoublek.rw6cam |
| 폰 앱 Mi Manager | `MiManager_V0.78.apk` | 0.78 (versionCode 78) |
| 소스 커밋 | 1fd209f | |

- 워치 앱 설치: MiFaceDown **"퀵앱 선택"** 또는 Mi Manager의 퀵앱 설치. **"펌웨어 선택"은 절대 사용 금지.**
- 폰: Mi Manager 첫 화면 → "카메라 셔터" → 접근성에서 **"Mi Manager 워치 셔터"** 켜기 (한 번만).
- 폰 카메라는 **삼성 기본 카메라**(com.sec.android.app.camera, 한국어 화면) 기준입니다.

## 왜 이렇게 만들었나

워치에 원래 있는 "카메라" 앱은 블루투스 HID(입력 기기) 방식인데, 중국판 펌웨어는 HID 켜기 명령(2/8)에 답하지 않아 쓸 수 없습니다(글로벌판에서는 됐던 기능). 그래서 워치에 새 퀵앱을 만들고, 폰에서는 접근성 서비스가 카메라 화면의 버튼을 대신 누르게 했습니다. 화면 내용은 버튼을 찾을 때만 보고 저장하거나 밖으로 보내지 않습니다.

## 워치 화면 사용법

- **오른쪽 아래 "사진 / 동영상"**: 고른 쪽이 흰색. 누르면 폰 카메라도 그 모드로 바뀜. 녹화 중에는 못 바꿈.
- **가운데 버튼**
  - 사진: 흰 원 → 누르면 촬영
  - 동영상: 빨간 원 → 누르면 녹화 시작
  - 녹화 중·일시정지 중: 빨간 네모 → 누르면 녹화 끝
- **왼쪽 아래 버튼**
  - 평소: 타이머. 누를 때마다 OFF → 3s → 5s → 10s (사진과 녹화 시작에 적용, 세는 중 다시 누르면 취소, 남은 초는 가운데에 표시)
  - 녹화 중: 일시정지(세로줄 두 개)
  - 일시정지 중: 빨간 세모 → 다시 촬영
- 폰 카메라가 닫혀 있으면 첫 누름은 카메라를 열기만 합니다("한 번 더 누르세요").
- 맨 위 글자 줄에 폰이 알려 준 결과가 뜹니다(찍었어요, 녹화 중, 일시정지 …).

## 동작 방식 (기술)

**워치 → 폰 신호** (퀵앱 interconnect, `{cam: 번호}`)

| 번호 | 뜻 |
|---|---|
| 1 | 사진 |
| 5 | 녹화 시작 |
| 8 | 녹화 끝 |
| 3 | 일시정지 ↔ 다시 촬영 |
| 6 | 동영상 모드로 |
| 7 | 사진 모드로 |
| 2 | (예전 1.3~1.4 워치 앱의 동영상 버튼, 폰에만 남겨 둠) |

**폰 → 워치 답**: `{r: "글", v: 0|1|2, m: 0|1}` — v = 0 안 찍는 중 / 1 녹화 중 / 2 일시정지, m = 0 사진 / 1 동영상. 워치는 누르자마자 화면을 바꾸고, 이 답으로 바로잡습니다.

**폰 쪽 (hub/…/rw6hub/ShutterService.java, 접근성 서비스)** — 삼성 카메라에서 확인한 이름들

| 무엇 | 화면에서 찾는 것 |
|---|---|
| 사진 촬영 | `normal_center_button` (설명 "사진 촬영") |
| 지금 모드 | `shooting_mode_list` 의 설명 "사진, 모드" / "동영상, 모드" / "싱글테이크, 모드" |
| 모드 칸 | `shooting_mode_item_layout` (글자 없음, 자리만 있음). 순서: 싱글테이크 · 사진 · 동영상 · 더보기 |
| 동영상 모드 준비됨 | 가운데 버튼 설명이 "녹화 시작"으로 바뀜 |
| 녹화 중 | `stop_button`(설명 "녹화 중지"), `recording_time` 이 보임 |
| 일시정지 / 다시 촬영 | `pause_button` — 설명이 "일시정지"면 녹화 중, "계속"이면 멈춘 상태 |

- **모드 바꾸기**: 지금 고른 모드 칸은 화면 가운데에 옵니다. 보이는 칸들 중 가운데 칸이 몇 번째인지로 순서가 바른지 거꾸로인지를 그 자리에서 판단해 목표 칸을 바로 누릅니다. 확인된 배치: 세움(0도) 가로 4칸 바른 순서 / 눕힘 90도 세로 4칸 **거꾸로** / 눕힘 270도 세로 4칸 바른 순서. 판단이 안 되는 배치면 화면 방향별로 기억해 둔 값(prefs `shutter` flip0~3)을 씁니다.
- **기다리기**: 누른 뒤에는 정해진 시간이 아니라 화면이 실제로 바뀔 때까지 0.3초마다 확인합니다(모드 이름, "녹화 시작" 버튼, 녹화 시작·끝, 일시정지 상태 — 최대 3~3.6초).
- **상태는 화면에서 읽음**: 앱이 따로 기억하지 않으므로 폰에서 직접 눌러도 어긋나지 않습니다.
- 한 가지 일을 처리하는 동안 들어온 누름은 넘깁니다(기록에 "앞의 일을 하는 중이라 넘김").
- 결과는 Mi Manager 기록에 "워치 셔터: …"로 남습니다. 문제가 생기면 **기록 복사**로 그 줄들을 보면 원인을 알 수 있습니다.

## 여기까지 오며 배운 것

1. `VIDEO_CAMERA` 인텐트는 삼성 카메라를 동영상 모드로 바꾸지 않음(화면만 깜빡).
2. 모드 줄의 "동영상" 글자는 접근성에 안 잡힘 → 글자로 찾는 방식 불가. 미리보기를 미는 방식은 엉뚱한 모드(싱글테이크)로 감.
3. 가운데 버튼 설명은 모드가 바뀌는 중에는 예전 값("사진 촬영")이 남아 있음 → 모드 판단은 `shooting_mode_list` 로, 누를 때는 "녹화 시작"이 된 뒤에.
4. 모드 칸 순서는 폰을 쥔 방향에 따라 뒤집힘 → 방향을 하나로 기억하면 헤맴.
5. 버튼 아이디에 늘 `pause`가 들어 있음 → 상태는 **설명**만 보고 판단해야 함.
6. 누른 직후엔 화면이 아직 안 바뀌어 있음 → 고정 시간(1.2초) 뒤 확인하면 성공도 실패로 읽힘.
7. 우리가 누른 것을 변수로 기억하면 한 번 어긋난 뒤 계속 틀림 → 화면에서 읽을 것.

## 알려진 한계

- 삼성 기본 카메라·한국어 화면 기준. 다른 카메라 앱이나 다른 언어에서는 버튼을 못 찾을 수 있음(사진은 셔터 자리 누르기로 대신함).
- 싱글테이크·사진·동영상이 아닌 모드("더보기" 안의 모드)에서 시작하면 모드 전환이 실패할 수 있음.
- 워치 화면이 꺼져 앱이 닫혔다 다시 열리면 워치 쪽 표시는 처음 상태(사진)로 돌아감. 다음 누름의 폰 답으로 맞춰짐.

# 안정 버전 기록

지금까지 가장 잘 동작한다고 확인한 버전입니다. 문제가 생기면 이 폴더의 파일로 되돌리면 됩니다.
(폰 앱 = `.apk`, 워치 앱 = `.rpk` → MiFaceDown **"퀵앱 선택"**으로 설치. "펌웨어 선택"은 절대 사용 금지)

## 메신저 알림 2.7 (2026-11-08 확정) — `noti-2.7/`

| | 버전 |
|---|---|
| 폰 앱 (RW6Noti.apk) | 2.7 (versionCode 18) |
| 워치 앱 (RW6Noti.rpk, 워치 표시 이름 "메신저 알림") | 2.3.0 (versionCode 18) |
| 소스 커밋 | a958e94 |

**동작 방식**
- 폰이 카톡·문자·고른 앱의 알림을 읽어 워치 앱으로 보냄. 워치 앱을 열면 **도착한 알림만** 바로 표시(목록·빈 화면 없음). 뒤로 스와이프 = 쌓인 목록, "끄기" = 그 알림 삭제 후 앱 닫기.
- **글 알림**: 이미지가 아니라 글(JSON)로 보내고 워치가 직접 그림 → 빠르고 긴 글도 OK. 카드에 앱 아이콘 · 대화방 · 보낸 사람 · 본문.
- **사진 알림**: "보낸 사람: 사진" 글 알림이 먼저 즉시 오고, 사진(JPEG 70, 가로 꽉 채움, 세로 최대 640px·비율 유지)이 도착하면 같은 자리를 바꿔 끼움.
- **빠르게 보내기**: 매번 워치 앱을 열고, 앱이 받을 수 있게 되는 순간 도착하도록 글은 약 10초간 짧은 간격으로 거듭 보냄(워치는 같은 알림을 한 번만 처리). 워치가 "받았어(ack)"를 보내면 즉시 멈춤.
- 폰 앱 설정: 글자 크기, 카카오톡/문자/그 밖의 앱 선택, 사진 함께 보내기, 사진 있는 알림만 보내기, 진동, 화면 깨우기, 워치 알림 목록에 "OO 알림 - N건" 표시.
- 폰 앱 "5. 최근 기록"에 알림마다 처리 결과가 남음 (누락 원인 확인용).

**확인된 체감 (사용자 측정, 2.5 기준)**: 화면 꺼짐 시 글 약 4초 → 2.6~2.7에서 더 줄임. 2.7에서 화면 꺼짐 시 누락 개선.

**알려진 한계**
- 카톡 "전체보기"가 필요한 아주 긴 글은 카톡이 알림에 앞부분만 넣어서 그만큼만 표시됨.
- 워치 화면이 꺼져 있으면 워치가 앱을 띄우는 시간만큼은 줄일 수 없음.
- 앱을 직접 열면 약 2.5초 검은 화면 뒤 목록이 나옴 (폰이 연 건지 구분할 방법이 없어서).
- 이미지 카드 높이를 크게(5000px) 했을 때 워치가 재시작됨 → 사진 카드는 세로 640px 한도 유지할 것.

## RW6 메모 1.7 — `memo-1.7/`

| | 버전 |
|---|---|
| 폰 앱 (RW6Memo.apk) | 1.7 (versionCode 8) |
| 워치 앱 (RW6Memo.rpk) | 1.4.0 (versionCode 5) |
| 소스 커밋 | 305d271 |

- 컬러노트 백업(.backup) 해독 → 워치로 전송(보기 전용, 잠긴 메모 제외). 비밀번호는 입력값 → 0000 → 빈값 순서로 자동 시도.
- 보낼 메모 선택: 최근 N개(기본 30) / 직접 고르기 / 전체. 일부만 보내면 워치 메모에 날짜순으로 **추가**, 전체는 통째로 교체.
- 메모를 묶어서 전송(700개도 수십 번 메시지), 끊기면 이어 보내기, 받는 동안 워치 화면 유지.
- 워치: 목록 40개씩(더 보기), 긴 메모는 문단 단위로 그림, 제목은 베젤에 안 가리게 아래로.
